# Portfolio — Santhosh Rubenraj Solomon

Personal portfolio of Santhosh Rubenraj Solomon — a product-minded backend & fintech
infrastructure engineer. Built with React + Vite + TypeScript, self-hosted fonts, and
custom CSS tokens (light/dark). Deployed to Firebase Hosting.

**Live:** https://santhoshrubenraj.web.app

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # static build → dist/
npm run preview  # preview the build
```

## Deploy

```bash
firebase deploy --only hosting
```
